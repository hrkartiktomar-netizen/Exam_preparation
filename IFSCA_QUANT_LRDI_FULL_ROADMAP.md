## Reality Check

Do not prepare as if Quant has a separate 10/25 cutoff. The official Phase I Paper 1 structure is:

| Section | Questions | Marks |
|---|---:|---:|
| General awareness with financial-sector awareness | 25 | 25 |
| English language | 25 | 25 |
| Quantitative aptitude | 25 | 25 |
| Reasoning | 25 | 25 |

Important constraints:

- Paper 1 is 100 marks in 60 minutes.
- Paper 1 has a paper-level minimum cutoff, not a separate Quant-only cutoff.
- Objective papers carry 1/4 negative marking.
- Phase I is for shortlisting. Final selection depends on Phase II plus interview.

Therefore, your Quant + LRDI target is not perfection. The target is controlled scoring:

| Area | Minimum stable target | Strong target |
|---|---:|---:|
| Quant including DI | 13-15/25 | 16-18/25 |
| Reasoning/LR | 15-17/25 | 18-20/25 |

Once you can repeatedly score around 30-36 marks from Quant + Reasoning combined, stop obsessing over aptitude and protect time for domain.

## Core Learning Rules

### Rule 1: Concept, Then Speed

Speed is not magic. It comes from:

- memorized arithmetic facts,
- recognizing standard question frames,
- clean scratch layout,
- not rereading data,
- leaving traps quickly.

For the first 6 weeks, do not time every problem. Build correctness. After that, time everything.

### Rule 2: One Topic Must Pass Four Gates

Every topic is complete only when it passes these gates:

1. Concept gate: you can explain the idea in plain language.
2. Untimed gate: you solve 25/30 correctly without time pressure.
3. Timed gate: you hit the topic speed target.
4. Mixed gate: you identify the topic inside a mixed mock.

Watching a video is not a gate. It is only input.

### Rule 3: Maintain An Error Notebook

Every wrong question gets one error code:

| Code | Meaning | Repair |
|---|---|---|
| C | Concept gap | Relearn the concept and solve 30 easy-to-medium questions |
| A | Arithmetic error | Tables, squares, fractions, percentage drills |
| R | Reading error | Underline conditions and rewrite data |
| L | Layout error | Improve table/diagram/scratch format |
| T | Time pressure | Timed sets after accuracy is stable |
| G | Guessing | Reduce attempts and use skip rules |

Review the error notebook every Sunday.

### Rule 4: Stop-Loss Rules

In the exam:

- Leave any Quant word problem if no equation forms within 45-60 seconds.
- Leave any LR puzzle if the base arrangement is not forming within 2.5-3 minutes.
- Do not guess between five options under negative marking.
- Return only if the easy pool is exhausted.

| 12 | Number series | Differences, products, squares/cubes, alternating | 5 Q in 6-8 min |

### Conceptual Notes For Key Topics

#### Simplification

Required understanding:

- BODMAS is not optional.
- "of" means multiplication.
- A root or power is handled before multiply/divide.
- When `?` appears inside an equation, isolate it step by step.

Practice ladder:

1. Pure integer BODMAS.
2. Fractions.
3. Roots and squares.
4. Percentages inside expressions.
5. Full exam-style mixed expressions.

#### Approximation

Required understanding:

- Round only enough to match options.
- If options are close, keep one more digit.
- Memorize square roots and common fraction-percent values.
- Approximation is not random rounding; it is controlled error.

Memorize:

- 1/2 = 50%
- 1/3 = 33.33%
- 2/3 = 66.67%
- 1/4 = 25%
- 3/4 = 75%
- 1/5 = 20%
- 1/6 = 16.67%
- 1/8 = 12.5%
- 3/8 = 37.5%
- 5/8 = 62.5%
- 7/8 = 87.5%
- 1/9 = 11.11%

#### Percentage

Required understanding:

- Percentage always needs a base.
- "A is 20% more than B" means A = 1.2B.
- "A is 20% less than B" means A = 0.8B.
- Percentage change = change/original x 100.

This topic feeds DI, P&L, SI/CI, ratio and finance-current-affairs numericals.

#### Ratio

Required understanding:

- Ratio parts are not actual values until multiplied by a common factor.
- Difference between ratio parts can reveal the common factor.
- In partnership, ratio is not just capital; it is capital x time.

#### Quadratic Equations

Use factorization, not the quadratic formula, for exam speed.

Method:

1. For `ax^2 + bx + c = 0`, compute `a x c`.
2. Find two factors with required sum/product.
3. Split middle term.
4. Get roots.
5. Compare all possible x roots with y roots.

Do not compare only one root with one root. Compare the full set.

#### Number Series

Check in this order:

1. Simple differences.
2. Difference of differences.
3. Multiplication/division pattern.
4. Square/cube plus or minus.
5. Alternating series.
6. Position-based pattern.
7. Plug options and verify the whole series.

For a weak-math beginner, "plug and verify" is not shameful. It is often the fastest safe method.

## Stage 3: DI Build

Duration: Weeks 10-18, overlapping with Quant.

Purpose: convert percentages and ratios into marks.

### DI Topic Ladder

| Order | DI type | Goal |
|---:|---|---|
| 1 | Simple table DI | Read rows/columns without panic |
| 2 | Percentage table DI | Convert percentages to numbers |
| 3 | Ratio table DI | Split totals into parts |
| 4 | Missing-data DI | Fill blanks systematically |
| 5 | Caselet DI | Convert paragraph into table |
| 6 | Bar/line/pie DI | Handle graph formats |
| 7 | Mixed DI | Exam readiness |

### Universal DI Method

For every DI set:

1. Read the title and units.
2. Identify rows and columns.
3. Mark what is total, part, percentage, ratio or average.
4. Precompute obvious values.
5. Build a mini-table on scratch.
6. Answer direct questions first.
7. Leave heavy multi-step questions for later.

### Caselet DI Method

For paragraph DI:

1. Read the whole caselet once without calculating.
2. Decide table structure.
3. Fill direct statements first.
4. Convert ratios/percentages second.
5. Use totals last.
6. Only then answer the 5 questions.

Most caselet mistakes happen because students start calculating before designing the table.

### DI Speed Targets

| Stage | Target |
|---|---|
| Beginner | 1 simple table set in 20 min |
| Developing | 1 table set in 15 min |
| Exam level | 1 table set in 10-12 min |
| Caselet beginner | 1 caselet in 20-25 min |
| Caselet exam level | 3/5 in 15 min |

### DI Daily Drill

Weeks 10-12:

- 1 simple table DI set every alternate day.
- Untimed but fully reviewed.

Weeks 13-16:

- 1 DI set daily.
- 15-minute timer.

Weeks 17 onward:

- Alternate table DI and caselet DI.
- One day per week: mixed DI sectional.

### Conceptual Notes For Key LR Topics

#### Inequality

Required understanding:

- Chain symbols carefully.
- Do not infer across broken links.
- `>` and `>=` are different.
- Either/or cases require complementary possibilities.

Speed target: 5 questions in 3 minutes.

#### Syllogism

Required understanding:

- "All A are B" does not mean all B are A.
- "Some" means at least one.
- "No" means complete exclusion.
- "Only a few" means some yes and some no.
- "Only A are B" means all B are A.
- Possibility conclusions are about whether a diagram can exist, not whether it must exist.

Speed target: 5 questions in 5-6 minutes.

#### Blood Relation

Required understanding:

- Draw generations vertically.
- Mark gender immediately.
- Mark marriages horizontally.
- Never assume gender unless given.
- "Only son/daughter" is a restriction.

Speed target: 5 standalone questions in 7 minutes, or one family set in 10-12 minutes.

#### Direction-Distance

Required understanding:

- Fix north at the top.
- Track coordinates if possible.
- Final direction is from reference point to target point.
- Shortest distance often uses Pythagoras.

Speed target: 5 questions in 6-8 minutes.

#### Seating Arrangement

Required understanding:

- Decide line/circle orientation first.
- Facing north/south changes left/right.
- In circular arrangements, facing inside/outside changes left/right.
- Use cases only when necessary.
- Kill invalid cases quickly.

Speed target:

- Easy linear set: 5 questions in 8-10 minutes.
- Moderate seating set: 5 questions in 12-15 minutes.

#### Floor/Flat Puzzles

Required understanding:

- Floors must be drawn as a grid.
- Fixed clues go first.
- Negative clues only eliminate positions.
- "Above/below" and "immediately above/below" are different.
- Flat Alpha/Beta or east/west must be labelled consistently.

Speed target: 5 questions in 12-15 minutes.

#### Month/Order/Scheduling

Required understanding:

- Make ordered slots.
- Mark month days if relevant.
- Use before/after clues carefully.
- Do not mix "between" with "gap".

Speed target: 5 questions in 10-14 minutes.

#### Critical Reasoning

Required understanding:

- Assumption: unstated idea needed for argument.
- Argument: strong if practical, relevant and directly tied to the statement.
- Course of action: feasible, immediate and addresses the problem.
- Cause-effect: distinguish correlation from causation.

This is medium priority. Do not spend more time here than on puzzles, syllogism and inequality.

### Scratchpad Formats

#### Quant Word Problem Scratchpad

Use this layout:

```text
Given:
Need:
Let:
Equation:
Solve:
Check:
```

Do not begin solving until "Need" is clear. Many beginner mistakes happen because the question asks for a difference, percentage, ratio or final selling price, and the student stops one step early.

#### DI Scratchpad

Use this layout:

```text
Rows:
Columns:
Total:
Known values:
Missing values:
Computed values:
Question order:
```

Always write units: rupees, people, hours, percent, km, kg. Unit mistakes are silent score killers.

#### LR Puzzle Scratchpad

Use this layout:

```text
Slots:
Fixed clues:
Negative clues:
Cases:
Rejected cases:
Final arrangement:
```

For floor/flat:

```text
Floor 5: __ / __
Floor 4: __ / __
Floor 3: __ / __
Floor 2: __ / __
Floor 1: __ / __
```

For linear seating:

```text
_ _ _ _ _ _ _ _
Left/right rule:
Facing direction:
```

For circular seating:

```text
Inside-facing: left = clockwise? right = anticlockwise?
Outside-facing: reverse it.
```

Write this rule before solving. It prevents the classic left/right collapse.

### When To Start Test Series

Do not buy or start full test series on day one. Use them in layers.

| Stage | Test type | Platform use |
|---|---|---|
| Month 1 | No full mocks | Self-made foundation tests |
| Month 2 | Mini topic tests | Free questions, book drills |

### When To Move From One Stage To The Next

| Move from | Move to | Required proof |
|---|---|---|
| NCERT foundation | Competitive Quant | 80% in foundation arithmetic |
| Untimed Quant | Timed Quant | 25/30 correct in a topic |
| Simple DI | Caselet DI | 4/5 in simple table DI twice in a row |
| Basic LR | Puzzle LR | Inequality/syllogism above 80% |
| Topic tests | Sectionals | At least 3 topics stable |
| Sectionals | Full mocks | Quant and LR sectionals above 60% |
| Paper 1 mocks | Phase I simulation | Paper 1 score safely above cutoff zone |

This prevents the most common beginner mistake: moving forward because videos are finished, not because skill is proven.

## Final Attempt Philosophy

Quant:

- First collect simplification/approximation.
- Then collect DI direct questions.
- Then quadratic and number series.
- Then arithmetic word problems.
- Leave trap problems.

DI:

- Table DI is your main target.
- Caselet DI is partial-scoring territory: 3/5 is acceptable.
- Do not let one DI set destroy the section.

LR:

- First collect inequality/syllogism/miscellaneous.
- Then easy direction/blood relation.
- Then one puzzle you can map cleanly.
- Avoid ego fights with long puzzles.

The exam rewards controlled scoring, not heroics.
