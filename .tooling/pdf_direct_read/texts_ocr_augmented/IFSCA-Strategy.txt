Coding Questions Strategy
The coding syllabus was largely aligned with SEBI IT Phase 2 (Paper 2). The questions were implementation-
based and ocused on core data structures and undamental algorithms rather than advanced competitive
programming concepts.
The ollowing types o questions were asked:
1. Write a program or Bubble Sort rom scratch (without using inbuilt sort unctions).
2. Merge two sorted arrays and return the nal sorted array (consider only valid non-zero elements).
3. Construct a Binary Search Tree (BST) rom a given array and print its inorder traversal.
4. Construct a BST rom a given array and compute its height.
5. Check whether a given string s occurs in another string t (substring check).
6. Implement Fibonacci using Dynamic Programming.
7. Find the minimum number o coins required (DP approach, not greedy).
Preparation Strategy
I you solve the Easy and Medium problems rom Striver’s DSA Sheet, it will be more than sucient or
this section.
Priority Areas
• Binary Trees (BT)
• Binary Search Trees (BST)
• Basic Sorting
• String Manipulation
• 1D Dynamic Programming
Trees (both BT and BST) should receive special attention, as multiple questions were directly based on
construction, traversal, and structural properties.
For Dynamic Programming, ocus only on standard easy-level problems such as Fibonacci, coin change (DP
version), and similar 1D array-based ormulations.
Graph problems are not required, as they are not mentioned in the syllabus.
Exam-Oriented Insight
The coding section tests:
• Conceptual clarity o data structures
• Clean implementation
• Understanding o time and space complexity
• Ability to write logic rom scratch
The questions are straightorward i undamentals are clear. Strong command over Trees and basic DP
ensures high scoring in this section.

Interview Preparation
The interview preparation was structured around three major pillars:
1. Technical Depth (IT Domain)
2. Organizational Awareness (IFSCA-specic knowledge)
3. Personal and Role Justication
1. Technical Preparation (IT-Focused)
For the IT stream, the interview is heavily technical. The panel primarily evaluates:
• Depth o understanding in core IT subjects
• Practical exposure in current work prole
• Conceptual clarity in AI/ML and Cybersecurity
A signicant portion o the discussion revolves around the candidate’s current organization and ongoing
work. Thereore, it is important to:
• Clearly explain your current role and responsibilities
• Justiy architectural and technical decisions taken in your projects
• Demonstrate real-world problem-solving exposure
AI/ML-related questions are usually theoretical and application-oriented rather than mathematical. Cy-
bersecurity questions oten ocus on attack vectors, mitigation strategies, and real-world implementation
scenarios.
2. IFSCA-Specifc Preparation
Strong institutional awareness is expected. Preparation should include:
• Overview and objectives o IFSCA
• Key provisions o the IFSCA Act, 2019
• Regulatory role in IFSC (GIFT City)
• Recent initiatives and achievements
Understanding the working o the SWIT portal (IFSCA portal) is important, including its purpose, stake-
holders, and regulatory workow.
Candidates should be able to articulate:
• How IFSCA difers rom RBI, SEBI, and IRDAI
• Its unied regulatory ramework within IFSC
• Its vision o making India a global nancial hub
3. Personal Justifcation and Motivation
“Why IFSCA?” is a critical question and must be answered convincingly.
The response should reect:
• Alignment between technical background and regulatory technology requirements
• Interest in nancial technology, innovation, and policy-driven impact
• Long-term commitment rather than short-term career movement
The panel expects maturity, clarity o intent, and awareness o the responsibility associated with a regulatory
role. BE HONEST !!!
